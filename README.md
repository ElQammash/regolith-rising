# Regolith Rising

A junior astronaut mission trainer by **Team AstraQuest** for the NASA Space Apps Challenge 2026.

The player runs a 4-person outpost on the Moon or on Mars for 30 turns and has to balance life support, radiation shielding, power and food. Every number in the simulation comes from a sourced NASA data file.

> 🚧 Work in progress. The design is in [docs/PRD.md](docs/PRD.md).
